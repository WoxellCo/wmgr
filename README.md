# wmgr
WMGR is a minimal and lightweight project manager for HTMW.
ISO C99 compliant.

current version: 0.2.0

## what's new
+ added CMake
+ library division, can be embedded in a larger project
+ added C++ library wrapper (unstable)
+ better organized default starter boilerplate
+ default starter boilerplate uses HTMW vT.7 features
+ better redefinitions
+ removed the linked list structure & functions, and added internal vector structure macros

WARNING! I know there are memory leaks and incomplete features, but I'm still testing it!
WARNING! WMGR is not currently supported on Windows
